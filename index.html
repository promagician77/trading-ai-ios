iOS technical plan by James

Screen capture → AI → voice pipeline

The Broadcast Upload Extension runs in a separate iOS process, so it keeps receiving frames even when Tradovate/TradingView is in the foreground.

Why Broadcast Upload Extension

iOS does not allow silent background screen capture. The Broadcast Upload Extension is the only Apple-approved mechanism. The user taps "Start Broadcast," and the extension receives frames in a separate process — even when Tradovate is in the foreground. 50MB memory limit in the extension, so frame processing must be lean.

Frame budget

ReplayKit delivers 30fps. Sending every frame to GPT-4o is too slow and expensive. Instead:

Frame diff filter
~1ms
JPEG compress
~5ms
Send to GPT-4o
~2-3s
State machine update
<1ms
Voice output
~200ms

Effective loop: ~1 analysis per 3 seconds. The state machine holds context between frames, so the AI doesn't restart from scratch each time.

What the AI sees vs. knows

Sees (each frame): candle colors, indicator overlays, zone boxes, timeframe label, price levels, Fib lines. GPT-4o Vision is strong at reading chart overlays.

Knows (system prompt): your complete trading rules. The prompt encodes every step of your setup — Context, Liquidity, Displacement, OB/FVG, Retest, Reaction, Confirmation — so the AI doesn't guess. It applies your rules, not generic TA.

Remembers (state): what it saw in the last 5-10 frames. If displacement happened 2 frames ago and price is now retesting the OB, it knows where it is in the sequence.

Your setup as a state machine

Click through each step to see how the app progresses through your trading logic. The app only alerts when the full sequence completes — not on individual signals.

WAIT
Context — AI reads the higher timeframe structure. Is the market in a trend or range? Which direction has the bias?
WAIT
Liquidity / Manipulation — Price sweeps a high or low, taking out stop losses. The AI recognizes a liquidity grab.
WAIT
Displacement — Strong, impulsive move away from the sweep. Creates a fair value gap. The AI checks candle body size and momentum.
WATCH LONG
OB / FVG identified — The displacement left an order block or FVG behind. The AI marks the zone and watches for price to return to it.
WATCH LONG
Retest — Price returns to the OB/FVG zone. The AI confirms price is in the zone, not just near it.
WATCH LONG
Reaction — Price shows rejection from the zone: wick, engulfing candle, or shift in lower timeframe structure.
CONFIRMED LONG
Confirmation — Full setup complete. AI speaks the alert. Only now, not before.
INVALIDATED
At any step: if price closes through the zone instead of rejecting, the setup is invalid. AI speaks "INVALIDATED" and resets to WAIT.

Voice alerts

Short, spoken feedback. No screen switching needed — the trader hears the alert while watching the chart.

WAIT

What the AI does NOT alert on

LONG
Price touches an order block → no alert. Touch without retest + reaction is not a setup.
SHORT
FVG appears → no alert. An FVG alone is a zone, not a trade.

Broadcast Upload Extension — SampleHandler.swift

This is the separate iOS process that receives screen frames while Tradovate is open.

// Runs in a separate process. 50MB memory limit.
import ReplayKit

class SampleHandler: RPBroadcastSampleHandler {
    let bridge = AppGroupBridge(group: "group.com.app.trading")
    var lastSent: CFAbsoluteTime = 0
    let minInterval: CFAbsoluteTime = 3.0 // 1 frame per 3s to AI

    override func processSampleBuffer(
        _ buffer: CMSampleBuffer,
        with type: RPSampleBufferType
    ) {
        guard type == .video else { return }
        let now = CFAbsoluteTimeGetCurrent()
        guard now - lastSent >= minInterval else { return }

        // Convert frame to JPEG (~100KB)
        guard let jpeg = buffer.toJPEG(quality: 0.6) else { return }

        // Check frame changed enough (pixel diff)
        if bridge.isDuplicate(jpeg) { return }

        // Send to main app via App Group shared memory
        bridge.write(jpeg)
        lastSent = now
    }
}

AI analysis + state machine — ChartAnalyzer.swift

Main app receives frames from the extension and sends to GPT-4o Vision.

func analyzeFrame(_ jpeg: Data) async {
    let prompt = """
    You are analyzing a live trading chart.
    Current state: \(stateMachine.current)
    Last 5 observations: \(stateMachine.history)

    Trading rules:
    \(tradingRules) // loaded from client's doc

    What do you see? Return JSON:
    {
      "timeframe": "5M",
      "structure": "bullish/bearish/range",
      "zones": [{"type":"OB/FVG/SD","bias":"bull/bear"}],
      "price_action": "retesting/rejecting/accepting",
      "next_state": "WAIT/WATCH_LONG/CONFIRMED/...",
      "confidence": 0.0-1.0,
      "reason": "one sentence"
    }
    """

    let result = try await openAI.vision(
        image: jpeg,
        prompt: prompt,
        model: "gpt-4o"
    )

    // Only transition if confidence > threshold
    if result.confidence > 0.7 {
        stateMachine.transition(to: result.nextState)
    }

    // Speak alert on state change
    if stateMachine.justChanged {
        voice.speak(stateMachine.current.alert)
    }
}

Voice output — VoiceEngine.swift

import AVFoundation

class VoiceEngine {
    private let synth = AVSpeechSynthesizer()

    func speak(_ text: String) {
        let utterance = AVSpeechUtterance(string: text)
        utterance.rate = 0.55  // slightly fast, not rushed
        utterance.voice = AVSpeechSynthesisVoice(
            language: "en-US"
        )
        // Interrupt previous alert if still speaking
        synth.stopSpeaking(at: .immediate)
        synth.speak(utterance)
    }
}

App Group IPC — how the extension talks to the main app

// Shared between extension (writes) and app (reads)
class AppGroupBridge {
    let container: URL

    init(group: String) {
        container = FileManager.default
            .containerURL(
                forSecurityApplicationGroupIdentifier: group
            )!
    }

    func write(_ frame: Data) {
        let url = container
            .appendingPathComponent("frame.jpg")
        try? frame.write(to: url)
        // Signal main app via Darwin notification
        CFNotificationCenterPostNotification(
            CFNotificationCenterGetDarwinNotifyCenter(),
            "com.app.trading.newframe" as CFNotificationName,
            nil, nil, true
        )
    }
}

Honest constraints

iOS shows a visible broadcast indicator (orange dot) while capturing. There is no way around this — it's an Apple requirement.
The Broadcast Extension has a 50MB memory limit. All frame processing must be lightweight.
GPT-4o Vision has ~2-3s latency per frame. The state machine bridges the gaps, but the system cannot react faster than the API.
App Store distribution is unlikely — Apple would reject an app that reads other apps' screens. TestFlight and enterprise distribution are the path.
